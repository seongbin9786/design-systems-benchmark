design-systems-benchmark · 실물 견본

같은 컴포넌트를 8개 시스템이 실제로 어떻게 만드는가

차트가 아니라 실물이다. 아래 모든 견본은 각 시스템 소스에서 해석한 실제 값 — 색·높이·radius·굵기 — 을 그대로 받아 이 페이지에서 렌더링된 것이다.

표시 규칙. 실측 은 지오메트리를 소스에서 읽어 확인한 것, 구성 은 그 시스템의 토큰 값으로 조립한 것이다(원본 컴포넌트의 내부 패딩·아이콘·전이까지 재현한 것은 아니다). 어느 견본이든 커서를 올리면 쓰인 실제 값이 나온다.

공용 CSS 로 모양을 통일하지 않았다 — 통일하면 비교 대상인 차이가 사라진다. 버튼 시트만 흰 배경에 고정했다(각 시스템의 라이트 테마 기준값이라 비교 조건을 같게 두려고).

1Button실측

각 시스템의 실제 높이·좌우 패딩·radius·글자 크기/굵기·테두리 두께로 그렸다. 같은 "버튼"이 32px에서 48px까지, 완전 각짐에서 완전 알약까지 벌어진다. 왼쪽 회색 글씨가 그 시스템의 실측 지오메트리다.

{{btn_table}}
시스템높이radius 패딩글자근거 경로

Carbon 만 유일하게 각지고(radius 0) 크다(48px). 패딩도 좌우 비대칭이다 (0 63px 0 15px) — 오른쪽에 아이콘 자리를 항상 비워두는 설계다. 반대쪽 극단은 Material Web 의 알약형(999px)과 Spectrum 의 완전 라운드(16px = 높이의 절반).

MUI 만 대문자 변환을 강제한다(text-transform: uppercase). 나머지 7개는 라벨을 그대로 쓴다.

2색 팔레트실측

semantic 슬롯 10칸을 각 시스템에서 찾아 실제 값을 칠했다. 사선 빗금은 그 시스템에 그 개념이 없다는 뜻 — 해석 실패가 아니다.

{{swatch_head}}
{{swatch_rows}}

brand 색이 유일하게 갈리는 축이다. Fluent 2 #0078d4 · Carbon #0f62fe · Ant Design #1677ff · MUI #1976d2 는 모두 파랑 계열인데, Material Web 은 보라(#6750a4), shadcn/ui 와 Polaris 는 거의 검정이다 — 브랜드색을 비워두고 제품이 채우게 하는 설계다.

success·warning 이 없는 시스템: {{no_status}}. 앞선 이름 단위 측정에서 "status:success/warning 이 5/8"로 나온 것의 실물이다. 상태색이 필요하면 직접 만들어야 한다.

7같은 화면을 8개 시스템으로구성

Card · Input · Badge · Alert · Button 을 각 시스템의 토큰만으로 조립했다. 같은 화면이 시스템에 따라 어떻게 다른 인상이 되는지 보는 용도다 — 원본 컴포넌트의 세부(내부 패딩·아이콘·전이·포커스 링)까지 재현한 것은 아니다.

{{uis}}

이 격자가 가장 정직한 비교다. 앞선 절들은 축 하나씩 떼어 봤지만, 실제 제품 인상은 radius·간격·글자 굵기·색 대비가 동시에 만들어낸다. Carbon 의 각진 48px 버튼과 Material Web 의 알약형 40px 버튼은 같은 화면을 전혀 다른 물건으로 만든다.
